# Lithuanian-law MCP servers listed on glama.ai (2026-11-26)

Read from the glama.ai listings and the linked repositories; claims are the publishers' own and were not tested.

| Server | Publisher | How to use | Data and features (as stated) |
|---|---|---|---|
| Lithuanian Law MCP | a Swedish company, Apache-2.0 | code archived 2026-07-07 (read-only); hosted gateway behind an OAuth sign-up, free tier and paid tiers | 12,045 statutes, 89,705 provisions in SQLite FTS; "in force / amended / repealed" per act; no past versions (roadmap); EU-basis tools; glama grades it F, "outdated data" |
| lt-legal-mcp | jurisatlas, MIT | not shown | legislation and court decisions, Markdown texts, citation checks |
| lt-eli-mcp | matematicsolutions, Apache-2.0 | local (PyPI) | title search and full text via data.gov.lt |
| TAAP MCP | irmastnt | not shown | data.gov.lt: consolidations, editions, amendments, annexes, Constitutional Court rulings; cached when the source is down |
| Teisynas | teisynas.lt | hosted, OAuth sign-in | acts, top court rulings, Seimas bills, tax authority comments, change alerts |
| Avokata | avokata.com | hosted, OAuth sign-in, "free during beta" | laws, 2.4 million court decisions, version on a date, citation checks |

What none of them states: a per-article "applies today" label worked out from the amending acts, with pending amendments
flagged; access with no sign-up; plain article pages that search engines and assistants fetch. Court decisions are where
several go further than this site, which carries none.
